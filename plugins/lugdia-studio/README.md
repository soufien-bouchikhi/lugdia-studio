# Plugin lugdia-studio

Règles de l’agence Lugdia, démarrage d’un projet client à partir de son brief (brief.lugdia.fr), et MCP de design et de contrôle : 21st.dev pour les composants, Playwright pour les captures, Chrome DevTools pour la performance, Context7 pour la documentation. Installe aussi taste-skill, impeccable et gsap-skills.

Installation, usage et maintenance : voir le README à la racine du dépôt.
